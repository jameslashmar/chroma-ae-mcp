# Tools (177)

Every tool the MCP serves, by group. Each tool's schema and description, as the agent sees them, live in `server/src/tools/`. The rules every write follows are in [SAFETY.md](SAFETY.md).

## Motion guidance

**Motion guidance comes with the tools.** Besides tools, the MCP serves Chroma's motion-director skill as MCP **prompts** (`motion_director`, with an optional `task`; `motion_review`, with an optional `comp`) and **resources** (`chroma-ae://guidance/motion-director/...`: the skill, its sources and seven reference files on timing and easing, choreography and transitions, type and layout, story and pacing, sound and captions, and review). Any client that supports prompts or resources gets them, including through the stdio relay while AE is closed. The text ships in `server/guidance/motion-director/`; `node scripts/sync-guidance.mjs` refreshes it from the skill, and a test fails if the compiled copy drifts.

**A project's motion language is part of its brief.** `ae_brief` has a `motion` field: a register (`ui_micro`, `brand_film`, `energetic`, `handmade`), signature ease, duration palette, stagger, overshoot budget, safe-zone platform, minimum text size, reading time, approved facts and beats. `ae_motion_review`, `ae_timing_check` and `ae_house_style_check` read their thresholds from it; anything left out comes from the register's defaults (`brand_film` when there is no brief).

## Native panels

CEP extensions open directly. AE's own Window-menu panels open through `app.executeCommand`, which does work through CEP (measured), but those commands **toggle**, so `ae_open_panel` refuses a native panel unless `allow_toggle` is set after checking with `ae_ui_screenshot`.

## Where it keeps things

- Data dir (`%LOCALAPPDATA%\chroma-ae-mcp`, `~/Library/Application Support/chroma-ae-mcp`): token, `settings.json` (auto checkpoints, taste, asset watch), `service.log`, `diagnostics/`, global `skills/`, `frames/`, `renders/` (and `renders/batches/<id>/` for `ae_render_batch`), `session-state.json` and `inflight-ops.json` (`ae_session_changes`), `learn-taste.json` (`ae_learn_taste`), `variants/` and `variant-picks.jsonl` (`ae_variants`), `tracks/` (the planar track store: `<track_id>.json`, newest 200 kept; re-basing never overwrites a stored track, a re-based copy gets its own id; `continue_track_id` adds frames to its own file), `patchfit/` (the state of a chunked `ae_patch_color_match`, newest 50 kept).
- Next to a project: `<name> chroma plates/` (the stills `ae_cleanplate_setup` and `ae_inpaint_plate` write, never over an existing file; needs a saved project), `<name>.brief.json`, `<name>.versions.json` (`ae_version_footage`'s log), `<name>.jobs.json` (`ae_multi_comp_apply`'s jobs), `<name>.deliver.json` (`ae_deliver_step`'s runs), `_collect/` (`ae_collect_files`: the .aep copy, `_Footage/`, `manifest.json` and the report), `ae-skills/`, `_assets/`, `_mcp_checkpoints/`, `_mcp_backups/` (copies taken by `ae_save`).
- Audio renders for `ae_audio_analyze` go to `renders/audio/` in the data dir.
